About the Model and the Animation

Equation

H = A + B/u + C·u, with A = 2λdp (λ = 0.5), B = 2γDm (γ = 0.7), and C = Cm + Cs. Mobile-phase mass transfer is Cm = ω(k)·dp²/Dm with the Golay-type ω(k) = (1 + 6k + 11k²) / [96(1 + k)²]. Stationary-phase mass transfer is Cs = (2/3)·k/(1 + k)²·df²/Ds, with film thickness df = 0.1·dp and Ds = 0.2·Dm.

Controls

  • Flow rate becomes linear velocity through a 150 × 4.6 mm column with total porosity 0.65.
  • Temperature changes Dm ∝ T/η (Wilke–Chang scaling, 1.0 × 10⁻⁹ m²/s at 25 °C) and the viscosity of an aqueous mobile phase. It doesn’t change k here; in a real separation, retention usually drops as temperature rises.
  • Particle size scales A with dp and C with dp², and sets the back-pressure ΔP = φηLu/dp² (φ = 700).
  • Analyte 1 SP Affinity (and Analyte 2 SP Affinity) set each analyte’s affinity for the stationary phase (SP), expressed as the retention factor k. Stronger affinity means longer stays in the film and a larger C term. Switching the C·u term off makes exchange between the phases instantaneous: the analyte is still retained and travels at u/(1 + k), slower than the mobile phase, but every molecule keeps the same average speed, so mass transfer adds no broadening.
  • Analyte 2 (tick the box beside Analyte 2 SP Affinity) adds a second compound, injected with the first. Either analyte can be switched off with its own tick box, as long as one stays on. The second compound has its own affinity for the stationary phase (its own k) but the same diffusion coefficient. Only its C term differs, so it has its own van Deemter curve (dashed). Resolution is Rs = (tR2 − tR1) / [2(σt1 + σt2)], using each band’s width in time at the outlet.

What the animation shows

Each molecule alternates between flowing with the mobile phase and sitting still in the stationary liquid film on a particle. On average it spends k/(1 + k) of its time in the film, so the band moves at u/(1 + k). The random lengths of those stays produce the C·u broadening. The A and B/u terms are added as random variation in each flowing step. The histogram of molecules and the Gaussian predicted from σ² = H·x come from the same numbers, so they should agree.

A real column has tens of thousands of plates, and a molecule enters and leaves the stationary phase tens of thousands of times. That is far too fast to see. The animation therefore shows a column with 81× fewer plates: band widths are magnified 9×. The stays in the film are also made longer and more regular than real ones, so each one is visible, while still producing exactly the C·u broadening. The up-and-down path of each molecule around the packing is illustrative only. All readouts give real-column values.
